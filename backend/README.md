# HemaNet backend

Flask API and worker (modular monolith, ADR-001), PostgreSQL 16, managed with
[uv](https://docs.astral.sh/uv/) (`uv.lock`). Architecture and conventions:
[docs/backend-foundation.md](../docs/backend-foundation.md).

```bash
make install                 # from the repo root: uv sync + npm ci
make up                      # start the stack (tests need its postgres)
make test                    # backend + frontend tests

# or directly, from backend/ (TEST_DATABASE_URL must point at a *_test database):
uv run pytest                # all tests
uv run pytest -m concurrency # only the genuinely concurrent tests
uv run ruff check . && uv run ruff format --check .
uv run lint-imports          # module boundaries
uv run mypy                  # strict type check
uv run bandit -q -c pyproject.toml -r .
```

Database migrations (Flask-Migrate):

```bash
FLASK_APP=wsgi uv run flask db migrate -m "describe change"   # needs DATABASE_URL
FLASK_APP=wsgi uv run flask db upgrade
```

Review every autogenerated migration by hand. It must downgrade cleanly, including any
enum types it creates.
